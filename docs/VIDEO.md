# Foreman — 3-minute video script (screen capture + voice-over)

0:00 Title card, 3 s. "Foreman. Hire agents like you would hire people."
0:05 Talking point over registry screenshot: "Enterprises are about to delegate real work to third-party agents.
     Every registry lists them. Nobody checks them. And afterwards nobody can say who did what."
0:20 Live UI. Type the work order (vendor comparison). Click Run. Plan appears: three subtasks with acceptance criteria.
0:40 Column 2 fills. "Foreman found five agents. It trusts none of them yet." Vetting runs: liveness, card, probe, canary.
     Zoom on `quickfix`: claims every skill, answers "Done." to a probe. Rejected. Zoom on `oracle`: confidently invents
     the Zorvath-9 clause. Rejected. Three hireable.
1:15 Column 3. Delegation to the researcher, receipt appears with hashes and cost. Analyst's first table fails the
     deterministic check: "total does not reconcile." Feedback goes back, attempt two passes the Gemini judge.
1:50 Column 4. Deliverable assembled. Click "verify chain": 40 events, signatures intact. Download the audit, open it,
     change one digit, POST it back: broken at event 17. "This is what an audit trail for agents looks like."
2:20 Architecture card, 15 s: ADK agents, A2A between them, Gemini Flash + Pro, seven Cloud Run services from one image.
2:40 Close: "Foreman doesn't make agents trustworthy. It makes trust checkable, before the work and after it."
     Repo and live URL on screen. End 2:55.

Record at 1440p, 30 fps, no music under the voice, captions on. Tools: QuickTime screen capture + Lulu's ElevenLabs voice
or Arnav's own voice (better for the judges). Keep every on-screen wait under 3 s by pre-warming the Cloud Run services.
